# Gurgaon Real Estate Market Analysis

## Project Overview
An Exploratory Data Analysis (EDA) project analyzing residential property listings in Gurgaon to identify pricing trends, premium localities, and factors affecting property prices.

## Objectives
- Identify the costliest property and most expensive localities.
- Compare ready-to-move and under-construction properties.
- Analyze the impact of RERA approval on prices.
- Study price trends by area, BHK configuration, and property type.
- Compare builder pricing and price per square foot.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- VS Code / Jupyter Notebook

## Project Workflow
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Group-wise comparisons and visualizations
5. Business insights and conclusions

## Dataset
Source: [Gurgaon Real Estate Dataset — Kaggle](https://www.kaggle.com/datasets/nikhilmehrahr26/gurgaon-real-estate-dataset)
